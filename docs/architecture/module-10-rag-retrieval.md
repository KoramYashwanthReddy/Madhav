# Architectural Design: Module 10 — RAG & Retrieval Engine

## Subsystem Boundary & Principles

Module 10 is designed as a standalone, provider-decoupled **Retrieval and RAG Foundation** for Max.

### Explicit Constraints

- **No Reasoning / Answer Generation**: Retrieval returns ranked results and citations. It does not synthesize natural language responses or execute model prompts.
- **No Agentic Behavior**: The module does not invoke tools or run background crawlers.
- **100% Offline Testability**: Zero required external API keys or heavy local neural network downloads.

## Domain Model Taxonomy

- **`Document`**: Indexed document source entity with content hash and lifecycle status.
- **`DocumentChunk`**: Atomic unit generated by `TextChunker` with character offsets.
- **`EmbeddingVector`**: High-dimensional vector representation.
- **`RetrievalQuery` & `RetrievalFilter`**: Query definition with metadata filtering rules.
- **`RetrievalResult` & `Citation`**: Ranked match with provenance metadata.
- **`RetrievalContextBuilder`**: Projection engine converting search results to Module 06 `ContextItem`s.
